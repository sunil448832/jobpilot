\subsection{Vision-Language Model Fine-tuning – Ultrasound (Echocardiography) Image Captioning (Freelance) \hfill \href{https://huggingface.co/sunil448832/blip-model}{HuggingFace Model}}
\begin{zitemize}
\item Constructed a \textbf{2,000-pair image-to-instruction dataset} (1,600 / 400 train / test split) mapping ultrasound-probe images to probe-manipulation instructions for a PLAX echocardiography view, with \textbf{pandas / NumPy} data preparation and text preprocessing.
\item Fine-tuned \textbf{LLaVA 1.6 (Mistral-7B)} with \textbf{LoRA} (r=128, $\alpha$=256) via \textbf{DeepSpeed ZeRO-3}, then \textbf{benchmarked} it against a \textbf{CLIP} retrieval baseline and a fine-tuned \textbf{BLIP} model to select the best-performing approach on held-out data.
\item Built end-to-end \textbf{data preparation, training, and evaluation} pipelines with \textbf{Weights \& Biases} tracking; published the fine-tuned \textbf{BLIP} model to the \textbf{HuggingFace Hub}.
\item \textbf{Stack:} PyTorch, HuggingFace Transformers, pandas, NumPy, LLaVA, DeepSpeed, LoRA, CLIP, BLIP, W\&B.
\end{zitemize}

\subsection{QA Bot for PAN Card Queries (RAG) \hfill \href{https://github.com/sunil448832/Natural-Language-Processing/tree/master/RAG(Retrieval\%20Augment\%20Generation)}{GitHub Repository}}
\begin{zitemize}
\item Developed a \textbf{RAG} pipeline for PAN card query answering over a custom document corpus, using \textbf{Sentence Transformers} (MiniLM-L6-v2) embeddings with \textbf{FAISS} vector retrieval.
\item Queried a \textbf{quantized Mistral-7B} for contextual response generation; deployed via \textbf{FastAPI}.
\item \textbf{Stack:} PyTorch, FAISS, HuggingFace, FastAPI.
\end{zitemize}
