\subsection{Vision-Language Model Fine-tuning – Image Captioning (Freelance) \hfill \href{https://huggingface.co/sunil448832/blip-model}{HuggingFace Model}}
\begin{zitemize}
\item Ran a three-way \textbf{model comparison} on a self-built \textbf{2{,}000-pair} dataset (\textbf{1{,}600 / 400} train-test split) to select the best-performing approach: \textbf{LLaVA 1.6 (Mistral-7B)} fine-tuned with \textbf{LoRA} (r=128, $\alpha$=256) via \textbf{DeepSpeed ZeRO-3}, a fine-tuned \textbf{BLIP} baseline, and a \textbf{CLIP} similarity retrieval baseline.
\item Built the \textbf{end-to-end pipeline} --- data preparation, model training, and evaluation --- with \textbf{Weights \& Biases} experiment tracking; published the fine-tuned \textbf{BLIP} model to the \textbf{HuggingFace Hub}.
\item \textbf{Stack:} PyTorch, HuggingFace Transformers, LLaVA, DeepSpeed, LoRA, CLIP, BLIP, W\&B.
\end{zitemize}
