# Job Search Tracker — Guide

File: [job-tracker.csv](job-tracker.csv) — open in Excel, Google Sheets, or LibreOffice Calc.

## How to use
- One row per role. Sort/filter by **Priority**, **Stage**, or **Region**.
- Update **Stage** as you move; set a **Follow-up Date** every time you're waiting on someone.
- Keep a tailored **Resume Version** per market (e.g. "Gulf", "India", "Remote").

## Columns
| Column | What goes in it |
|---|---|
| Company / Role / Location | The basics |
| Region | India / UAE / Remote — for filtering |
| Work Mode | On-site / Hybrid / Remote |
| Source | Where you found it (Indeed, LinkedIn, referral, company site) |
| Job Link | Direct URL to the posting |
| Expected/Posted Salary | Posted range, or your target if not posted |
| Date Applied | When you submitted |
| Stage | See stages below |
| Next Action | The single next thing YOU must do |
| Follow-up Date | When to chase if no reply |
| Contact/Recruiter | Name + how to reach them |
| Referral? | Yes/No — referrals convert far better |
| Resume Version | Which tailored resume you sent |
| Priority | High / Medium / Low |
| Notes | Anything else (interview feedback, comp discussed) |

## Stage values (use these consistently)
`Interested` → `To Apply` → `Applied` → `Recruiter Screen` → `Technical/Case` → `Onsite/Final` → `Offer` → `Negotiating` → `Accepted` / `Rejected` / `Withdrawn` / `Ghosted`

## Tips
- **Follow up** ~5 business days after applying if no response; mark `Ghosted` after 2–3 weeks silence.
- In the UAE, salary is negotiated at offer — put your **target** (AED/month, tax-free) in the salary column so you anchor consistently.
- Aim to always have **3–5 rows in active stages** (Screen or beyond) to keep leverage.
